# Новая тень — Dark Fantasy Platformer

2D-платформер на Phaser 3 (vanilla JS, без сборщика). Уровень 1: тропинка через мрачный готический город от начала улицы до таверны.

## Концепция
Играешь за тень, крадущуюся по ночной улице. **Свет убивает** — факелы, фонари, окна, лунные пятна и конус фонаря вражеского «оловянного солдатика» мгновенно убивают при касании. Нужно двигаться короткими перебежками от тени к тени.

## Запуск
Нужен любой статический HTTP-сервер (из-за ES-модулей `file://` не сработает):

```bash
python3 -m http.server 8080
# или
npx serve .
```

Открой `http://localhost:8080/index.html`.

## Управление
- `A`/`D` или `←`/`→` — движение
- `Пробел` / `W` / `↑` — прыжок

## Структура
- `index.html` — точка входа, подключает Phaser 3 с CDN
- `src/main.js` — конфиг игры и список сцен
- `src/scenes/` — Boot → Preload → Level1 → Level2Stub (заглушка перехода)
- `src/entities/` — Player, Soldier (враг с фонарём), Torch, Lamp, WindowLight, SkyManager (луна/тучи), Rat
- `src/utils/hazard.js` — проверка пересечения игрока со световыми зонами
- `assets/generate_assets.py` — Python/Pillow скрипт, который процедурно рисует все PNG-спрайты (прозрачный фон) в `assets/sprites/`. Картинки — плейсхолдеры, нарисованные кодом, без стороннего арта.

Персонажи (ГГ и солдатик) по требованию собраны из частей: `*_body` (тело+голова), `*_arm_left`, `*_arm_right` — руки накладываются отдельными спрайтами и покачиваются при ходьбе.

Пересобрать спрайты:
```bash
python3 -m venv .assetenv && .assetenv/bin/pip install Pillow
.assetenv/bin/python assets/generate_assets.py
```
