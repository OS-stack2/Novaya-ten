# Новая тень — Godot-порт (Dark Fantasy Platformer)

Порт уровня 1 с Phaser 3 на Godot 4.x (GDScript). Та же идея: тень крадётся по
мрачной готической улице, **свет убивает** — факела, фонари, окна, лунные
пятна и конус фонаря вражеского «оловянного солдатика» мгновенно убивают при
касании.

## Запуск

### Вариант А — просто кликнуть (Windows)
1. Скачай Godot 4.x (**Standard**, не .NET-версию): https://godotengine.org/download/windows/
2. Распакуй `Godot_v4.x-stable_win64.exe`, переименуй в `godot.exe` и положи
   рядом с `run_game.bat` в эту же папку (где лежит `project.godot`).
3. Двойной клик по `run_game.bat`.

Если Godot уже установлен и добавлен в PATH — `run_game.bat` найдёт его сам,
копировать рядом не обязательно.

### Вариант Б — через редактор
1. Установи Godot 4.x.
2. Открой Godot → Import → укажи `project.godot` из этой папки.
3. F5 (Run Project).

## Управление
- `A`/`D` или `←`/`→` — движение
- `Пробел` / `W` / `↑` — прыжок

## Структура
- `project.godot` — конфиг проекта (разрешение, гравитация, инпут-маппинг)
- `scenes/Level1.tscn`, `scenes/Level2Stub.tscn` — сцены-пустышки с корневым
  `Node2D`; вся сцена строится программно в соответствующем `.gd`-скрипте
  (аналогично тому, как уровень собирался в Phaser-версии)
- `scripts/Player.gd` — `CharacterBody2D`: тело + две руки как `Sprite2D`,
  покачивание рук при ходьбе через `Tween`
- `scripts/Soldier.gd` — враг-патруль, конус света — `CollisionPolygon2D`
  внутри `Area2D`
- `scripts/Torch.gd` — факел: 3 фазы (ярко → затухание → угольки), хазард
  выключается на фазе угольков (`Area2D.monitoring`)
- `scripts/Lamp.gd` — фонарь: покачивание, статичный хазард-прямоугольник
- `scripts/WindowLight.gd` — окно: idle → свечение по кайме штор → открыто
  (хазард активен только в открытом состоянии)
- `scripts/SkyManager.gd` — параллакс (небо/замок/дальние и средние здания
  через `ParallaxBackground`/`ParallaxLayer` с `motion_mirroring`), луна,
  тучи, лунные пятна-хазарды
- `scripts/Rat.gd` — декоративные патрулирующие крысы (3 вида текстур)
- `assets/sprites/` — те же процедурно сгенерированные PNG-спрайты
  (прозрачный фон), что и в веб-версии на Phaser

Хазарды (всё, что убивает) реализованы через `Area2D` с сигналом
`body_entered` — попадание `Player` в зону вызывает `Player.die()`
(плейсхолдер смерти: затухание + поворот + возврат на последнюю точку на
земле).

## Известные ограничения / что доделать
- Респаун — последняя точка на земле вне опасности, без явных чекпоинтов
- Уровень 2 — заглушка (`Level2Stub.tscn`), переход срабатывает при входе в
  таверну в конце уровня
- Headless-прогон (`godot --headless --path .`) на машине разработчика
  несколько секунд отработал без единой ошибки в выводе — но живого теста
  в редакторе с визуальным контролем не было, стоит открыть и посмотреть
